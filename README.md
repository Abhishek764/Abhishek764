## ✦ About

<img align="right" src="flor-ascii.jpg" width="220" alt="ascii art"/>

**Hey, I'm Abhishek Kumar** — software engineer from Noida, working across backend systems, cloud/DevOps, and AI/ML.

I like problems that live where those fields overlap: observability pipelines, developer tooling, and the unglamorous reliability work that keeps systems honest. Most of what I build ends up open-source — I'd rather ship something people can actually run than let it rot in a private repo.

## ✦ Featured Project — litti

<div align="center">

<a href="https://github.com/Abhishek764/litti">
  <img src="https://github-readme-stats.vercel.app/api/pin/?username=Abhishek764&repo=litti&theme=github_dark&bg_color=0D1117&border_color=30363D&title_color=FFFFFF&text_color=8B949E&icon_color=FFFFFF" alt="litti"/>

</div>

**A lie detector for the Approve button.** `litti` proves a human actually read what they approved before an AI agent acts on it — risk tiering, comprehension checks, and hash-chained receipts that make "I reviewed it" verifiable instead of a vibe.

> Built because agents now ship code, move money, and touch prod on a human's single click — and that click was becoming a rubber stamp.
