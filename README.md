## ✦ About

<img align="right" src="flor-ascii.jpg" width="220" alt="ascii art"/>

**Hey, I'm Abhishek Kumar** — software engineer from Noida, working across backend systems, cloud/DevOps, and AI/ML.

I like problems that live where those fields overlap: observability pipelines, developer tooling, and the unglamorous reliability work that keeps systems honest. Most of what I build ends up open-source — I'd rather ship something people can actually run than let it rot in a private repo.

Lately: contributing to production codebases (SigNoz, open-design), building AI-assisted developer tools, and sharpening Go + TypeScript.

- 🔭 Building developer tools and AI-powered apps
- 🌱 Deep in distributed systems, observability, and Go
- 🤝 Open to open-source collaboration
- 📫 **work.abhishek91@gmail.com** · [Portfolio](https://abhiyad.vercel.app/)
